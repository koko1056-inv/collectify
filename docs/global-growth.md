# グローバルに人気が出るツールにするために（ベンチマークと打ち手）

結論から。Collectify の強みは「推しのグッズが、公式の情報で数万件そろっている」ことと、「持ってる・ほしい・交換が1つのアプリで回る」こと。海外で伸びるには、**①英語で探せて、②Discogs のように“データベースそのものが検索から入口になり”、③Letterboxd / Untappd のように“記録がそのまま共有される”**、の3つが核になる。

## 参考にするアプリ

| アプリ | 学ぶこと | Collectify への当てはめ |
|---|---|---|
| **Discogs**（レコード） | 世界共通のデータベース＋マーケットプレイス。ユーザーがデータを直し、足す。検索流入が大半 | 公式グッズ DB を英語・多言語で整える。品番・販売店・発売日・バージョンの違いを持つ。ユーザー編集は管理者承認つきで開く |
| **Letterboxd**（映画） | 記録そのものがプロフィールになり、リスト・レビューが共有される。ファン同士のつながりが強い | 「コレクション」「ほしいものリスト」「作品別のコンプ率」を、プロフィールとして美しく見せ、SNS に貼れるようにする（共有カードは作成済み） |
| **Untappd**（ビール） | チェックイン→バッジ→フレンドの反応、で習慣化。バッジが収集欲を刺激 | 「N 個目のお迎え」「作品コンプ」などのバッジと、コメント・反応へのポイント（今回追加） |
| **Collectr / CLZ**（TCG・コミックの管理） | 価格と合計金額の見える化。バーコード・写真で素早く登録 | 相場（中古・フリマ）の目安、コレクションの金額、写真からの登録（AI で商品を当てる） |
| **Weverse**（K-POP のファンプラットフォーム） | アーティスト公式と、ファン、ショップが1か所。国をまたいだファンコミュニティ | 作品・推しごとの「ハブ」を作る（その作品のグッズ・投稿・交換が1画面）。多言語の翻訳つきコメント |
| **Mercari / Vinted / Whatnot**（個人間取引・ライブ販売） | 取引の安全（エスクロー・評価）と、送料・梱包の仕組みで信頼をつくる | 交換は評価制度と配送の手順を持っている。国をまたぐ取引は難しいので、最初は国内同士 |
| **Strava / Spotify Wrapped / Duolingo**（習慣化と共有） | 連続記録、年次のまとめ、友だちとの比較が自然な拡散になる | 「今年のお迎え Wrapped」、連続ログイン（作成済み）、友だちとコンプ率比較 |

## いまの強みと、グローバルでの穴

**強み**: 公式カタログ約 5.6 万件（ガチャ・一番くじ・プライズ・カフェ・カードまで）、毎日の自動追加、交換、投稿、共有カード、サブスクとポイント、決済の通貨対応。

**穴**:
1. 言語が日本語と英語だけで、作品名・商品名は日本語のまま。英語名で検索してもほとんど出ない（作品名の英語表記は今回追加）。
2. 検索エンジンから入る入口が弱い（商品の公開ページはあるが、多言語・構造化データ・サイトマップの整備が要る）。
3. 海外のファンが「買う」手段がない（日本の店は海外発送しないことが多い）。
4. 信頼と安全（通報・ブロック・退会・法務）が公開の前提を満たしていない（`docs/launch-readiness.md`）。
5. 新しい商品が出たことを知らせる仕組み（リリースカレンダー・通知）が、ファンにとっての“毎日開く理由”になりきっていない。

## やること（優先順）

### 1. 公開の前提をそろえる（〜1か月）
`docs/launch-readiness.md` の A（認証・退会・法務・通報・画像・ヘッダー）を終える。海外のユーザーを受け入れる前提として、特に **実メール認証（または Apple / Google ログイン）・退会・プライバシーポリシー（GDPR 対応）・同意バナー**。これがないと、海外で広告や PR を打てない。

### 2. “英語で見つかる” を作る（1〜3か月）
- 作品名・キャラ名・グッズ種別の**英語名と別名（エイリアス）**をデータベースに持つ（作品名は今回追加、次は商品名・キャラ名）。検索は英語・ローマ字・日本語のどれでも当たるように。
- 商品の**公開ページを SEO 対応**（`hreflang`、構造化データ `Product`、サイトマップ、OGP の多言語化）。Discogs と同じく「商品名で検索したら Collectify が出る」状態を目指す。
- 言語を、**英語に加えて繁体字中国語・韓国語・タイ語・インドネシア語・スペイン語**などへ。日本のグッズへの関心が高い地域から。優先は、アプリストアの検索ボリュームと SNS の反応で決める。
- 商品名の**機械翻訳の表示切り替え**（原文を残し、翻訳を併記）。

### 3. 海外のファンが“手に入れる”導線（2〜4か月）
- 商品ごとの「買えるところ」に、**公式ストア・転送/代行購入サービス**（Buyee・ZenMarket・Neokyo など）へのリンクを置く。アフィリエイト提携を検討（収益にもなる）。
- 交換は**まず国内同士**。国をまたぐ交換は、住所の秘匿（アプリ内の住所なし配送ガイドは作成済み）、関税・送料、紛争時の対応が要るので、評価制度が育ってから段階的に。
- **相場の見える化**（中古・フリマの価格の目安）。Collectr / Discogs のように“金額”が見えると、登録の動機が増える。

### 4. 習慣と拡散のループ（継続）
- **リリースカレンダーと通知**: 推しの作品の新商品・再販・イベント（カフェ・くじ）を毎日届ける。毎日の自動追加（作成済み）が土台になる。
- **記録＝共有**: コレクションカード、コンプ率、“今年のお迎え Wrapped” を、X・Instagram・TikTok の縦動画の比率で出す。
- **交流にポイント**（今回追加: 投稿・コメント・反応・交換完了）。ポイントは「使える先」（AI 機能、ショップ）とセットで価値が出るので、使い道の見せ方も磨く。
- **ファンのコミュニティ**: 作品ごとのハブ、リスト（「推しの部屋」「ガチャ全種そろえ」）、フォロー。クリエイター（コレクター系の発信者）を作品ごとに数人つかみ、紹介コードで成長を共有する。
- **ウェブ→アプリ**: ウェブで入口をつくり、アプリ（iOS / Android）へ。ストアの説明文・スクリーンショットも言語ごとに。

### 5. 信頼・安全・権利（常に）
- 通報・ブロック・モデレーション・24 時間以内の対応、退会、データ書き出し。
- カタログ画像の**権利者向けの削除依頼窓口**、可能なら公式との提携（正式にデータや画像を使える）。ここが最大の事業リスクで、公式とのつながりがあれば最大の差別化にもなる。

### 6. 測るもの
- **活性化**: 登録後 5 分以内に最初のグッズを追加した割合。
- **継続**: D1 / D7 / D30、週に1回以上グッズを追加・投稿した人の数（WAU）。
- **拡散**: 共有カードからの新規登録数、招待コード経由の割合、1 人あたりの招待数。
- **取引**: 交換の申請から完了までの割合・日数、評価の平均。
- **収益**: 無料から有料への転換率、ポイントの消費先、アフィリエイトのクリック。
- 解析は同意を取ってから（EU/UK）。イベント設計を先に決める（Mixpanel の現行実装は見直し）。

## ロードマップ（案）

| 期間 | 目標 | 主な内容 |
|---|---|---|
| 〜1か月 | 公開できる状態に | 認証・退会・法務・通報・画像・ヘッダー、エラー監視 |
| 1〜3か月 | 英語圏で見つかる | 英語名・別名の検索、商品ページの SEO、英語の表現磨き、リリース通知 |
| 3〜6か月 | アジア圏へ | 繁体字・韓国語・タイ語・インドネシア語、代行購入のアフィリエイト、作品ハブ |
| 6〜12か月 | 取引と収益 | 相場表示、国をまたぐ交換の試験、公式との提携、アプリ内課金の最適化 |

## 最初の一歩（すぐできること）
1. `docs/launch-readiness.md` の「まず 1 週間」を終える。
2. 英語名・別名を、上位 30 作品の商品名・キャラ名から埋める（毎日の自動追加の手順に、英語名の付与を足す）。
3. 商品の公開ページに、構造化データと多言語の `hreflang` を入れる。
4. 対象国を絞った小さな検証（英語圏の特定の作品のファンコミュニティで、招待制のクローズドβ）。
